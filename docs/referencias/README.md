# Catálogo de referencias oficiales

Toda regla (`docs/reglas/`) cita al menos una referencia de este catálogo. Solo valen
fuentes oficiales. Las copias de los documentos se guardan en `docs/referencias/<país>/`.

## Fuentes oficiales autorizadas

| País | Organismo | Ámbito | Web |
|------|-----------|--------|-----|
| España | ICAC | Normativa contable | icac.gob.es |
| España | BOE | Legislación española | boe.es |
| España | Agencia Tributaria (AEAT) | Normativa tributaria | agenciatributaria.es |
| R. Dominicana | DGII | Impuestos internos | dgii.gov.do |
| R. Dominicana | ICPARD | Normativa contable / profesional | icpard.org |

Para añadir un país, el usuario define primero sus fuentes oficiales en esta tabla.

## Formato del ID

- `REF-<PAÍS>-NNN`: documento oficial (p. ej. `REF-ES-001`).
- `REF-DEC-NNN`: decisión documentada del usuario (solo para reglas técnicas `CORE`).
